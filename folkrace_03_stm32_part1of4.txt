# STM32 Dual-Motor FOC Architecture

The Folkrace drivetrain is driven by **two independent STM32G474CBT6 microcontrollers**, each controlling a single axle with two direct-drive brushless motors running hardware-accelerated Field Oriented Control (FOC):

1. **Front Axle Controller**: Drives Front-Left (M1) and Front-Right (M2) direct-drive motors.
2. **Rear Axle Controller**: Drives Rear-Left (M3) and Rear-Right (M4) direct-drive motors.

Both microcontrollers run identical high-performance firmware, receiving individual velocity setpoints from the **ESP32 Main** chassis master over high-speed UART and executing closed-loop velocity FOC at 20 kHz.

---

## 1. System Specifications & Features

* **MCU**: STM32G474CBT6 (Arm Cortex-M4F @ 170 MHz with hardware CORDIC and trig accelerators).
* **Motors**: GM3506 Brushless Gimbal Motors (24N22P, 11 pole pairs, 12V supply, zero-backlash direct-drive).
* **Encoders**: 2x MT6816 14-bit magnetic angle encoders connected via **two independent hardware SPI peripherals** (SPI1 and SPI2) for deterministic, low-latency position acquisition.
* **Control Frequencies**:
  * **20.0 kHz Hard Real-Time Commutation**: Center-aligned PWM generation on TIM2 and TIM3.
  * **4.0 kHz Velocity PID Loop**: Downsampled velocity tracking with back-EMF feedforward (`Kv = 130 RPM/V`).
  * **25 Hz Telemetry Stream**: Reports actual shaft RPM and diagnostic metrics.
* **Calibration & Non-Linearity Compensation**:
  * 128-point Stepped Harmonic Linearization Look-Up Table (LUT) to eliminate magnet non-linearity and cogging torque.
  * Automatic electrical zero alignment and phase symmetry tuning.

## 4. Communication Protocol with ESP32 Main

Communication occurs over USART1 at **921,600 baud, 8N1** with structured binary packets:

### Downlink (ESP32 Main -> STM32):
* **Format**: 17-byte packet containing 0xAA sync byte, target Left RPM (float32), target Right RPM (float32), reserve fields, and an XOR checksum.
* **Rate**: 400 Hz synchronous loop.

### Uplink (STM32 -> ESP32 Main):
* **Format**: 18-byte packet containing 0x55 sync byte, actual Left shaft RPM (float32), actual Right shaft RPM (float32), voltage/health flags, and an XOR checksum.
* **Rate**: 25 to 100 Hz.

---

## 5. Firmware Build & USB DFU Flashing

The firmware is built using PlatformIO and uploaded over native USB via DFU:

```bash
# Build firmware
pio run -e stm32_dual_foc

# Flash over USB DFU bootloader
pio run -e stm32_dual_foc -t upload
```

> [!TIP]
> If flashing over USB DFU, ensure the board is in bootloader mode (BOOT0 pulled High on reset, or using the hands-free DFU jump routine).

#!/usr/bin/env python3
"""
FOLKRACE — Automated Closed-Loop Phase Angle Equalizer & Symmetry Tuner (GM3506 @ 12V)
======================================================================================
Protocol:
  1. Sets gentle alignment voltage (2.5V @ ~0.35A).
  2. Runs baseline 11-Pole Hysteresis-Compensated Calibration ('c').
  3. Establishes baseline zero angle (theta_0) and safety bounds (+/- 0.10 rad / +/- 5.7 deg elec).
  4. Runs iterative closed-loop voltage tests (+/- 4.0V) to find directional asymmetry.
  5. Dynamically nudges motor.zero_electric_angle within safe bounds to maximize symmetry (>98%).
  6. Computes balanced True Motor KV and applies optimal settings to SimpleFOC controller.
"""

import sys
import time
import math
import re
import argparse
import serial
import serial.tools.list_ports


def find_stm32_port():
    ports = list(serial.tools.list_ports.comports())
    for p in ports:
        desc = (p.description or "").lower()
        if "stm" in desc or "ch340" in desc or "cp210" in desc or "usb" in desc:
            return p.device
    return ports[0].device if ports else None


class AutoSymmetryTuner:
    def __init__(self, port, baud=921600, test_voltage=4.0, max_nudge_rad=0.10):
        self.port = port
        self.baud = baud
        self.test_voltage = float(test_voltage)
        self.max_nudge_rad = float(max_nudge_rad) # Safety bound: +/- 0.10 rad (~ +/- 5.7 deg elec)
        self.ser = None
        self.base_zero_angle = None
        self.optimal_zero_angle = None

    def connect(self):
        print(f"\n[+] Connecting to STM32 on {self.port} @ {self.baud} baud...")
        self.ser = serial.Serial(self.port, self.baud, timeout=0.05)
        time.sleep(0.5)
        self.ser.reset_input_buffer()
        print("[+] Connected successfully.\n")

    def disconnect(self):
        if self.ser and self.ser.is_open:
            try:
                self.ser.write(b"u0.0\nx\n")
                self.ser.flush()
                self.ser.close()
            except Exception:
                pass

    def send_cmd(self, cmd_str):
        if self.ser and self.ser.is_open:
            self.ser.write(f"{cmd_str}\n".encode("utf-8"))
            self.ser.flush()

    def read_telemetry_sample(self, duration_s=0.6, settle_s=0.4):
        time.sleep(settle_s)
        t_end = time.time() + duration_s
        rpm_samples = []
        angle_samples = []

        while time.time() < t_end:
            line = self.ser.readline().decode("utf-8", errors="ignore").strip()
            if not line:
                continue

            # Check for stall
            if "SAFETY SHUTDOWN" in line:
                print("\n[!] EMERGENCY STALL DETECTED! Aborting test.")
                self.send_cmd("x")
                return 0.0, 0.0

            # Telemetry format: Ctrl: ... | Target: ... | Actual: +120.4 RPM | Angle: 45.2 deg | ...
            m_rpm = re.search(r'Actual:\s*([+-]?\d+\.?\d*)\s*RPM', line)
            m_ang = re.search(r'Angle:\s*([+-]?\d+\.?\d*)\s*deg', line)

            if m_rpm:
                try:
                    rpm_samples.append(float(m_rpm.group(1)))
                except ValueError:
                    pass
            if m_ang:
                try:
                    angle_samples.append(float(m_ang.group(1)))
                except ValueError:
                    pass

        mean_rpm = sum(rpm_samples) / max(1, len(rpm_samples))
        std_rpm = math.sqrt(sum((x - mean_rpm)**2 for x in rpm_samples) / max(1, len(rpm_samples)))
        return mean_rpm, std_rpm

    def run_baseline_calibration(self):
        print("================================================================================")
        print(" PHASE 1: 11-POLE BASELINE ELECTRICAL ZERO CALIBRATION")
        print("================================================================================")
        print("[*] Setting optimal alignment voltage: 3.70V (Current ~ 0.55A)")
        self.send_cmd("y3.7")
        time.sleep(0.1)

        print("[*] Triggering 11-Pole Multi-Point Calibration ('c')...")
        self.send_cmd("c")

        t_start = time.time()
        mean_zero_found = None

        while time.time() - t_start < 20.0:
            line = self.ser.readline().decode("utf-8", errors="ignore").strip()
            if not line:
                continue

            if "Pole #" in line or "GRADE" in line or "Alignment" in line or "SimpleFOC" in line:
                print(f"    {line}")

            if "motor.zero_electric_angle =" in line:
                m = re.search(r'motor\.zero_electric_angle\s*=\s*([0-9]+\.[0-9]+)', line)
                if m:
                    mean_zero_found = float(m.group(1))

            if "CALIBRATION REJECTED" in line:
                print("\n[!] Calibration rejected by firmware. Please check wiring / sensor.")
                return False

            if "SimpleFOC Static Code Parameters" in line:
                break

        if mean_zero_found is None:
            # Fallback default
            mean_zero_found = 0.97555
            print(f"[!] Warning: Using default base zero: {mean_zero_found:.5f} rad")

        self.base_zero_angle = mean_zero_found
        self.optimal_zero_angle = mean_zero_found

        print(f"\n[+] Baseline Electrical Zero Angle established: {self.base_zero_angle:.5f} rad ({self.base_zero_angle * 180.0 / math.pi:.2f} deg)")
        print(f"[+] Safety Nudge Range: [{self.base_zero_angle - self.max_nudge_rad:.5f} rad to {self.base_zero_angle + self.max_nudge_rad:.5f} rad] (±{self.max_nudge_rad * 180.0 / math.pi:.2f}°)")
        print("--------------------------------------------------------------------------------\n")
        return True

    def test_bidirectional_speed(self, test_voltage):
        # 1. Forward Spin (+V): 1.5s acceleration + 1.0s sampling
        self.send_cmd(f"u{test_voltage:.2f}")
        fwd_rpm, fwd_std = self.read_telemetry_sample(duration_s=1.0, settle_s=1.5)

        # Coast to zero
        self.send_cmd("u0.0")
        time.sleep(1.0)

        # 2. Reverse Spin (-V): 1.5s acceleration + 1.0s sampling
        self.send_cmd(f"u-{test_voltage:.2f}")
        rev_rpm, rev_std = self.read_telemetry_sample(duration_s=1.0, settle_s=1.5)

        # 3. Stop
        self.send_cmd("u0.0")
        time.sleep(0.8)

        fwd_mag = abs(fwd_rpm)
        rev_mag = abs(rev_rpm)
        delta_rpm = fwd_mag - rev_mag
        max_mag = max(fwd_mag, rev_mag, 1.0)
        symmetry_pct = (min(fwd_mag, rev_mag) / max_mag) * 100.0

        return {
            "fwd_rpm": fwd_mag,
            "rev_rpm": rev_mag,
            "delta_rpm": delta_rpm,
            "symmetry_pct": symmetry_pct,
            "fwd_std": fwd_std,
            "rev_std": rev_std
        }

    def optimize_symmetry(self, max_iterations=7):
        print("================================================================================")
        print(" PHASE 2: AUTOMATED CLOSED-LOOP PHASE ANGLE NUDGING & OPTIMIZATION")
        print(f" Target Test Voltage : ±{self.test_voltage:.2f} V")
        print(f" Target Symmetry     : > 98.0 % (|Δ RPM| < 12.0 RPM)")
        print(f" Maximum Bounds      : ±{self.max_nudge_rad:.4f} rad (±{self.max_nudge_rad * 180.0 / math.pi:.2f}° elec)")
        print("================================================================================")
        print("Iter | Zero Angle (rad) | Nudge (rad) | Forward RPM | Reverse RPM | Delta RPM | Symmetry | Status")
        print("-----+------------------+-------------+-------------+-------------+-----------+----------+-------")

        current_angle = self.base_zero_angle
        best_symmetry = 0.0
        best_angle = current_angle
        best_data = None

        history = []
        for it in range(1, max_iterations + 1):
            # Apply candidate zero electric angle
            self.send_cmd(f"j{current_angle:.5f}")
            time.sleep(0.05)

            data = self.test_bidirectional_speed(self.test_voltage)
            nudge_from_base = current_angle - self.base_zero_angle

            is_valid = (data["fwd_rpm"] > 100.0 and data["rev_rpm"] > 100.0)
            if is_valid:
                history.append({
                    "angle": current_angle,
                    "delta": data["delta_rpm"],
                    "fwd": data["fwd_rpm"],
                    "rev": data["rev_rpm"],
                    "sym": data["symmetry_pct"]
                })

            if is_valid and data["symmetry_pct"] > best_symmetry:
                best_symmetry = data["symmetry_pct"]
                best_angle = current_angle
                best_data = data

            status = "BALANCED" if (is_valid and (data["symmetry_pct"] >= 98.0 or abs(data["delta_rpm"]) < 10.0)) else "TUNING"

            print(f" #{it:02d} | {current_angle:16.5f} | {nudge_from_base:+11.5f} | {data['fwd_rpm']:10.1f}  | {data['rev_rpm']:10.1f}  | {data['delta_rpm']:+9.1f} | {data['symmetry_pct']:7.1f}% | [{status}]")

            if is_valid and (data["symmetry_pct"] >= 98.0 or abs(data["delta_rpm"]) < 10.0) and it >= 2:
                print("\n[+] Perfect 1:1 Directional Symmetry achieved!")
                break

            # Secant root finding interpolation
            pos_pts = [p for p in history if p["delta"] > 0]
            neg_pts = [p for p in history if p["delta"] < 0]

            if pos_pts and neg_pts:
                best_pos = min(pos_pts, key=lambda p: abs(p["delta"]))
                best_neg = min(neg_pts, key=lambda p: abs(p["delta"]))
                d_diff = best_pos["delta"] - best_neg["delta"]
                if abs(d_diff) > 2.0:
                    next_angle = best_neg["angle"] - best_neg["delta"] * (best_pos["angle"] - best_neg["angle"]) / d_diff
                else:
                    next_angle = (best_pos["angle"] + best_neg["angle"]) * 0.5
            else:
                probe_step = - data["delta_rpm"] * 0.000015
                probe_step = max(-0.0020, min(0.0020, probe_step))
                next_angle = current_angle + probe_step

            # Enforce safety bounds relative to base_zero_angle
            min_bound = self.base_zero_angle - self.max_nudge_rad
            max_bound = self.base_zero_angle + self.max_nudge_rad

            if next_angle < min_bound:
                next_angle = min_bound
                print(f"    [!] Reached lower safety bound ({min_bound:.5f} rad). Clamping.")
            elif next_angle > max_bound:
                next_angle = max_bound
                print(f"    [!] Reached upper safety bound ({max_bound:.5f} rad). Clamping.")

            current_angle = next_angle
            time.sleep(0.2)

        self.optimal_zero_angle = best_angle
        # Apply optimal angle
        self.send_cmd(f"j{self.optimal_zero_angle:.5f}")
        time.sleep(0.05)

        # Final Verification
        print("--------------------------------------------------------------------------------")
        print("\n================================================================================")
        print(" PHASE 3: FINAL VERIFICATION & BALANCED KV EXTRACTION")
        print("================================================================================")

        mean_speed = (best_data['fwd_rpm'] + best_data['rev_rpm']) * 0.5
        true_kv = mean_speed / self.test_voltage
        ke = 1.0 / (true_kv * (2.0 * math.pi / 60.0))
        kt = ke

        print(f" Baseline Zero Electric Angle : {self.base_zero_angle:.5f} rad ({self.base_zero_angle * 180.0 / math.pi:.2f}°)")
        print(f" Optimal Neutral Zero Angle   : {self.optimal_zero_angle:.5f} rad ({self.optimal_zero_angle * 180.0 / math.pi:.2f}°)")
        print(f" Optimal Applied Phase Nudge  : {self.optimal_zero_angle - self.base_zero_angle:+.5f} rad ({(self.optimal_zero_angle - self.base_zero_angle) * 180.0 / math.pi:+.2f}° elec)")
        print(f" Forward Speed @ ±{self.test_voltage:.1f}V       : {best_data['fwd_rpm']:.1f} RPM")
        print(f" Reverse Speed @ ±{self.test_voltage:.1f}V       : {best_data['rev_rpm']:.1f} RPM")
        print(f" Final Directional Symmetry   : {best_data['symmetry_pct']:.1f} % (Δ = {best_data['delta_rpm']:+.1f} RPM)")
        print(f" Balanced True Motor KV       : {true_kv:.1f} RPM/V")
        print(f" Back-EMF Constant (Ke)       : {ke:.5f} V*s/rad")
        print(f" Torque Constant (Kt)         : {kt:.5f} N*m/A")
        print("================================================================================")

        # Apply KV to SimpleFOC
        self.send_cmd(f"q{true_kv:.1f}")
        print(f"[+] Applied KV ({true_kv:.1f} RPM/V) and Neutral Zero Angle to STM32 controller.\n")


def main():
    parser = argparse.ArgumentParser(description="Automated Closed-Loop Phase Angle Equalizer & Symmetry Tuner")
    parser.add_argument("--port", type=str, default=None, help="Serial COM port (default: auto-detect)")
    parser.add_argument("--baud", type=int, default=921600, help="Serial baud rate (default: 921600)")
    parser.add_argument("--volt", type=float, default=4.0, help="Test voltage in V (default: 4.0V)")
    parser.add_argument("--max-nudge", type=float, default=0.05, help="Max safe nudge in rad (default: 0.05 rad / ~2.86 deg)")
    args = parser.parse_args()

    port = args.port or find_stm32_port()
    if not port:
        print("[-] Error: No serial port found. Please connect STM32 and try again.")
        sys.exit(1)

    tuner = AutoSymmetryTuner(port=port, baud=args.baud, test_voltage=args.volt, max_nudge_rad=args.max_nudge)
    try:
        tuner.connect()
        if tuner.run_baseline_calibration():
            tuner.optimize_symmetry()
    except KeyboardInterrupt:
        print("\n[!] Tuner interrupted by user.")
    finally:
        tuner.disconnect()
        print("[+] Done.")


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""
pin_solver.py
=============
STM32G474 Mathematical Pinout Solver & Hardware Peripheral Verifier
Target: WeAct Studio STM32G474CBT6 Core Board (LQFP48 Footprint, Dual 2x12 Headers)

Priorities:
  1st Priority: Hardware peripheral correctness (working timers, SPI, UART, zero pin collisions).
  2nd Priority: Physical spacing & wiring clustering (motor wiring on Header P2, comms on Header P1).
"""

import sys
import math
from itertools import product

# ==============================================================================
# 1. HARDWARE REGISTER & ALTERNATE FUNCTION (AF) DATABASE (STM32G474 LQFP48)
# Source: STMicroelectronics Datasheet DS12288
# ==============================================================================
STM32_AF_REGISTERS = {
    # TIM2 (32-bit General Purpose Timer, Complementary/Standard PWM)
    "TIM2_CH1": ["PA0", "PA5", "PA15"],
    "TIM2_CH2": ["PA1", "PB3"],
    "TIM2_CH3": ["PA2", "PB10"],
    "TIM2_CH4": ["PA3", "PB11"],

    # TIM3 (16-bit General Purpose Timer, Standard PWM)
    "TIM3_CH1": ["PA6", "PB4"],
    "TIM3_CH2": ["PA4", "PB5"],
    "TIM3_CH3": ["PB0"],
    "TIM3_CH4": ["PB1"],

    # SPI1 (High-speed hardware SPI, up to 42.5 MHz)
    "SPI1_SCK":  ["PA5", "PB3"],
    "SPI1_MISO": ["PA6", "PB4"],
    "SPI1_MOSI": ["PA7", "PB5"],
    "SPI1_NSS":  ["PA4", "PA15"],

    # SPI2 (Independent high-speed hardware SPI, up to 42.5 MHz)
    "SPI2_SCK":  ["PB13"],
    "SPI2_MISO": ["PB14", "PA10"],
    "SPI2_MOSI": ["PB15", "PA11"],
    "SPI2_NSS":  ["PB12"],

    # USART1 (Telemetry communication highway)
    "USART1_TX": ["PA9", "PB6"],
    "USART1_RX": ["PA10", "PB7"],
}

# Protected silicon pins that MUST NOT be used for general IO:
FORBIDDEN_PINS = {
    "PA11": "USB_DM (Native USB CDC Serial)",
    "PA12": "USB_DP (Native USB CDC Serial)",
    "PA13": "SWDIO (Hardware Debug Interface)",
    "PA14": "SWCLK (Hardware Debug Interface)",
    "PB8":  "BOOT0 (Hardware Boot Pin & Button)",
}

# ==============================================================================
# 2. PHYSICAL 2D PIN COORDINATES (WeAct STM32G474 4-Row Board: P1 & P2 Dual Rows)
# Grid: (col, row) in 2.54 mm pitch units.
# Col 0: P1 Outer, Col 1: P1 Inner, Col 4: P2 Inner, Col 5: P2 Outer.
# ==============================================================================
PIN_COORDS = {
    # Header P1 (Left Side - Digital Communications & Sensors)
    "PB12": (0, 3), "PB14": (0, 4), "PA9": (0, 5), "PA11": (0, 6),
    "PA15": (0, 7), "PB4": (0, 9), "PB6": (0, 10), "PB8": (0, 11),
    "PB13": (1, 2), "PB15": (1, 3), "PA8": (1, 4), "PA10": (1, 5),
    "PA12": (1, 6), "PB3": (1, 7), "PB5": (1, 8), "PB7": (1, 9), "PB9": (1, 10),

    # Header P2 (Right Side - Power Inverter & Motor PWM)
    "PB2": (4, 3), "PB0": (4, 4), "PA7": (4, 5), "PA5": (4, 6),
    "PA3": (4, 7), "PA1": (4, 8), "PC14": (4, 10),
    "PB11": (5, 3), "PB1": (5, 5), "PA6": (5, 6), "PA4": (5, 7),
    "PA2": (5, 8), "PA0": (5, 9), "PC15": (5, 10), "PC13": (5, 11),
}


def calc_distance(pin1, pin2):
    if pin1 not in PIN_COORDS or pin2 not in PIN_COORDS:
        return 0.0
    c1 = PIN_COORDS[pin1]
    c2 = PIN_COORDS[pin2]
    return math.sqrt((c1[0] - c2[0]) ** 2 + (c1[1] - c2[1]) ** 2)


# ==============================================================================
# 3. MATHEMATICAL CONSTRAINT SATISFACTION & OPTIMIZATION SOLVER
# ==============================================================================
def solve_stm32_pinout():
    """
    Solves the pin allocation via exhaustive constraint evaluation:
      - Enforces strict hardware alternate function validity from the datasheet.
      - Enforces injectivity (zero pin collisions).
      - Excludes reserved system pins (USB, SWD, BOOT0).
      - Optimizes for hardware clustering: all motor signals on Header P2,
        all digital sensors & comms on Header P1.
    """
    search_space = {
        "M1_PWM_A": [("PA5", "TIM2_CH1 (AF1)"), ("PA0", "TIM2_CH1 (AF1)")],
        "M1_PWM_B": [("PA1", "TIM2_CH2 (AF1)")],
        "M1_PWM_C": [("PA2", "TIM2_CH3 (AF1)")],
        "M1_EN":    [("PA3", "GPIO Output")],

        "M2_PWM_A": [("PA6", "TIM3_CH1 (AF2)")],
        "M2_PWM_B": [("PA4", "TIM3_CH2 (AF2)")],
        "M2_PWM_C": [("PB0", "TIM3_CH3 (AF2)")],
        "M2_EN":    [("PA7", "GPIO Output")],

        "ENC1_SCK":  [("PB3", "SPI1_SCK (AF5)"), ("PA5", "SPI1_SCK (AF5)")],
        "ENC1_MISO": [("PB4", "SPI1_MISO (AF5)"), ("PA6", "SPI1_MISO (AF5)")],
        "ENC1_MOSI": [("PB5", "SPI1_MOSI (AF5)"), ("PA7", "SPI1_MOSI (AF5)")],
        "ENC1_CS":   [("PA15", "SPI1_NSS (AF5)"), ("PA4", "SPI1_NSS (AF5)")],

        "ENC2_SCK":  [("PB13", "SPI2_SCK (AF5)")],
        "ENC2_MISO": [("PB14", "SPI2_MISO (AF5)"), ("PA10", "SPI2_MISO (AF5)")],
        "ENC2_MOSI": [("PB15", "SPI2_MOSI (AF5)"), ("PA11", "SPI2_MOSI (AF5)")],
        "ENC2_CS":   [("PB12", "SPI2_NSS (AF5)")],

        "UART_TX":   [("PA9", "USART1_TX (AF7)"), ("PB6", "USART1_TX (AF7)")],
        "UART_RX":   [("PA10", "USART1_RX (AF7)"), ("PB7", "USART1_RX (AF7)")],
    }

    signals = list(search_space.keys())
    candidate_options = [search_space[s] for s in signals]

    total_permutations = 1
    for opt in candidate_options:
        total_permutations *= len(opt)

    valid_solutions = []

    for combo in product(*candidate_options):
        assignment = {signals[i]: combo[i][0] for i in range(len(signals))}
        af_names = {signals[i]: combo[i][1] for i in range(len(signals))}
        pins = list(assignment.values())

        # Mathematical Proof 1: Strict Injectivity (no pin collisions)
        if len(set(pins)) != len(pins):
            continue

        # Mathematical Proof 2: Reserved/Forbidden Pins check
        if any(p in FORBIDDEN_PINS for p in pins):
            continue

        # Physical spacing metrics:
        # Distance from high dv/dt PWM switching pins to sensitive SPI MISO data lines
        pwm_pins = [assignment[f"M{m}_PWM_{ph}"] for m in (1, 2) for ph in ("A", "B", "C")]
        miso_pins = [assignment["ENC1_MISO"], assignment["ENC2_MISO"]]
        min_pwm_to_miso = min(calc_distance(pwm, miso) for pwm in pwm_pins for miso in miso_pins)

        # Distance between SPI clock and SPI MISO
        spi1_dist = calc_distance(assignment["ENC1_SCK"], assignment["ENC1_MISO"])
        spi2_dist = calc_distance(assignment["ENC2_SCK"], assignment["ENC2_MISO"])

        # Header clustering score: prefer placing all motor lines on Header P2 (col >= 4)
        # and all comms on Header P1 (col <= 1)
        motor_pins = pwm_pins + [assignment["M1_EN"], assignment["M2_EN"]]
        comms_pins = [assignment[s] for s in signals if s not in motor_pins]
        motor_on_p2 = sum(1 for p in motor_pins if PIN_COORDS.get(p, (0, 0))[0] >= 4)
        comms_on_p1 = sum(1 for p in comms_pins if PIN_COORDS.get(p, (5, 5))[0] <= 1)

        # Score function: Priority 1 is valid hardware (satisfied above).
        # Priority 2 is clean separation & spreading.
        score = (motor_on_p2 * 100) + (comms_on_p1 * 50) + (min_pwm_to_miso * 5.0) + spi1_dist + spi2_dist

        valid_solutions.append({
            "score": score,
            "min_pwm_miso_pitch": min_pwm_to_miso,
            "min_pwm_miso_mm": min_pwm_to_miso * 2.54,
            "spi1_dist_pitch": spi1_dist,
            "spi1_dist_mm": spi1_dist * 2.54,
            "spi2_dist_pitch": spi2_dist,
            "spi2_dist_mm": spi2_dist * 2.54,
            "assignment": assignment,
            "af_names": af_names,
        })

    valid_solutions.sort(key=lambda x: x["score"], reverse=True)
    return total_permutations, valid_solutions
