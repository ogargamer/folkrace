# STM32 Main Board Pinout Map

This document provides a beautifully structured, color-coded dual-row layout map of all headers on the STM32 main board.

## Color Coding Legend
* <code style="background-color: #ffebee; color: #c62828; font-weight: bold; padding: 2px 4px; border-radius: 4px;">Power / VCC / V+</code> — System Voltage Rails
* <code style="background-color: #eceff1; color: #37474f; font-weight: bold; padding: 2px 4px; border-radius: 4px;">GND</code> — System Ground Reference
* <code style="background-color: #e3f2fd; color: #0d47a1; font-weight: bold; padding: 2px 4px; border-radius: 4px;">Motor Control</code> — PWM Outputs and Enable Lines
* <code style="background-color: #e0f2f1; color: #004d40; font-weight: bold; padding: 2px 4px; border-radius: 4px;">Encoders</code> — Quadrature Encoder Channel Signals (EXTI)
* <code style="background-color: #f3e5f5; color: #4a148c; font-weight: bold; padding: 2px 4px; border-radius: 4px;">Communications</code> — UART Interface to ESP32 Master
* <code style="background-color: #e8f5e9; color: #1b5e20; font-weight: bold; padding: 2px 4px; border-radius: 4px;">UI / LED / Button</code> — Status LEDs and User Interface Control
* <code style="background-color: #fffde7; color: #f57f17; font-weight: bold; padding: 2px 4px; border-radius: 4px;">System / Debug</code> — SWD Debug and MCU Reset line
* <code style="background-color: #f5f5f5; color: #9e9e9e; font-weight: normal; padding: 2px 4px; border-radius: 4px;">Unused GPIO</code> — Spare IO pin available for custom expansion
* <code style="background-color: #fafafa; color: #bdbdbd; font-weight: normal; padding: 2px 4px; border-radius: 4px; border: 1px dashed #e0e0e0;">NC</code> — No Connect (Pin is not connected)
